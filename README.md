# Дела — список задач

Простой To-Do List в стиле бумажного ежедневника. Тестовое задание.

**Демо:** _ссылка появится после деплоя на Vercel_

## Возможности

- Добавление задач (кнопка или Enter). Пустой ввод не добавляется, длина до 200 символов.
- Отметка выполненных: текст перечёркивается линией «от руки».
- Удаление задач.
- Сохранение в `localStorage`: задачи остаются после обновления страницы.
- Синхронизация между открытыми вкладками.
- Счётчик и полоса прогресса.
- Mobile-first: поле ввода закреплено внизу экрана у большого пальца, учтены вырезы экрана.
- Светлая и тёмная тема по системной настройке.
- Доступность: подписи для экранного диктора, видимый фокус, работа с клавиатуры, `prefers-reduced-motion`.

Если хранилище браузера недоступно или данные в нём повреждены, приложение не падает, а начинает с пустого списка.

## Стек

React, TypeScript, Vite, обычный CSS. Шрифты Cormorant Garamond, Manrope и JetBrains Mono подключены локально через `@fontsource` (только латиница и кириллица). Тесты: Vitest и Testing Library. Линтер: oxlint, форматирование: Prettier.

## Структура

```
src/
  types.ts           тип Todo
  storage.ts         чтение и запись localStorage с защитой от битых данных
  useTodos.ts        состояние и действия: add, toggle, remove
  id.ts              генерация id
  formatDate.ts      дата в шапке («вторник, 3 ноября»)
  components/        TodoForm, TodoList, TodoItem, Progress
  App.tsx            сборка страницы
  index.css          дизайн: токены, темы, mobile-first вёрстка
```

## Запуск

Нужен Node.js 22+ (версия указана в `.nvmrc`).

```bash
npm install
npm run dev        # http://localhost:5173
```

| Команда             | Что делает                                           |
| ------------------- | ---------------------------------------------------- |
| `npm run dev`       | дев-сервер                                           |
| `npm test`          | тесты                                                |
| `npm run lint`      | линтер                                               |
| `npm run typecheck` | проверка типов                                       |
| `npm run format`    | форматирование                                       |
| `npm run build`     | production-сборка в `dist/`                          |
| `npm run preview`   | просмотр сборки с теми же заголовками, что на Vercel |

## Деплой на Vercel

1. Зайдите на [vercel.com/new](https://vercel.com/new) и импортируйте этот репозиторий из GitHub.
2. Ничего не меняйте: настройки берутся из `vercel.json` (Vite, `npm run build`, папка `dist`).
3. Нажмите **Deploy**.

После деплоя каждый push в `main` выкатывается автоматически, а для каждого pull request создаётся превью.

`vercel.json` также задаёт заголовки безопасности (Content-Security-Policy, X-Frame-Options и другие) и долгий кэш для файлов из `/assets`.

После первого деплоя стоит заменить `/og.png` в `index.html` на полный адрес (`https://<ваш-домен>/og.png`), чтобы превью ссылки показывалось во всех мессенджерах, и вписать ссылку на демо в начало этого файла.

## Проверки

GitHub Actions на каждый push в `main` и pull request запускает линтер, проверку форматирования, типы, тесты и сборку.
