# To-Do List Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Сайт «Список задач» с добавлением, отметкой, удалением и сохранением в `localStorage`, готовый к деплою на Vercel.

**Architecture:** Одностраничное React-приложение без бэкенда. Вся работа с `localStorage` изолирована в `storage.ts`, состояние и действия — в хуке `useTodos`, компоненты только отображают и вызывают действия.

**Tech Stack:** React + Vite + TypeScript, обычный CSS, `@fontsource`, Vitest + Testing Library + jsdom, ESLint + Prettier, GitHub Actions, Vercel.

**Spec:** `docs/superpowers/specs/2026-11-03-todo-list-design.md`

## Global Constraints

- Ключ хранилища: `todo-app:v1`. Максимальная длина текста задачи: 200.
- Интерфейс на русском; `<html lang="ru">`.
- Цвета (светлая): фон `#F3EDE2`, текст `#1C1A17`, акцент `#D9482B`. Тёмная: фон `#17140F`, текст `#EDE6D8`, акцент `#F0643F`. Все цвета — CSS-переменные на `:root`.
- Шрифты: Cormorant Garamond (заголовок), Manrope (текст), JetBrains Mono (номера, счётчик); подмножества latin + cyrillic.
- Mobile-first: базовые стили для 320px+, расширение через `@media (min-width: 640px)`. Цели нажатия ≥ 44px, шрифт поля 16px, `env(safe-area-inset-*)`.
- Тексты: заголовок «Дела»; кнопка `aria-label="Добавить задачу"`; поле `placeholder="Новое дело…"`, `aria-label="Новая задача"`; пустое состояние «Чистая страница. Запишите первое дело.»; счётчик `осталось N из M`, при всех выполненных — «Всё сделано».
- Node 20 (`.nvmrc`, `engines`).
- Никаких UI-библиотек и внешних запросов в рантайме.

## Review Focus

1. Длинное слово без пробелов (200 символов) — переносится внутри строки, горизонтальной прокрутки нет (Task 5, проверка на 320px).
2. `localStorage` бросает исключение при чтении и записи (приватный режим Safari) — приложение работает в памяти (Task 2).
3. Удаление при `prefers-reduced-motion` или без события `animationend` — задача всё равно удаляется (Task 4: удаление через таймаут-запасной вариант).
4. HTML в тексте задачи (`<b>x</b>`) — отображается как текст (Task 4).
5. Длинный список на телефоне — закреплённая снизу форма не перекрывает последнюю задачу (Task 5, проверка скриншотом).

### Task 3: Хук `useTodos`

**Files:**

- Create: `src/useTodos.ts`, `src/id.ts`
- Test: `src/useTodos.test.ts`

**Interfaces:**

- Consumes: `loadTodos`, `saveTodos`, `parseTodos`, `STORAGE_KEY`, `Todo` (Task 2).
- Produces: `MAX_TODO_LENGTH = 200`; `useTodos(): { todos: Todo[]; add(text: string): boolean; toggle(id: string): void; remove(id: string): void }`. `add` возвращает `false` для пустого после `trim()` текста. `createId(): string` в `src/id.ts` — `crypto.randomUUID()` при наличии, иначе `Date.now().toString(36) + Math.random().toString(36).slice(2)`.

- [ ] **Step 1: Тесты** (`renderHook` + `act`)
  - `add trims text and prepends new todo`: `add('  a ')`, `add('b')` → `todos.map(t => t.text)` равно `['b', 'a']`, `completed` false
  - `add rejects empty and whitespace-only text`: `add('')`, `add('   ')` возвращают `false`, список пуст
  - `add truncates text to 200 chars`
  - `toggle flips completed both ways`
  - `remove deletes only the given todo`
  - `persists changes to localStorage`: после `add('a')` → `JSON.parse(localStorage.getItem('todo-app:v1'))[0].text === 'a'`
  - `restores todos on new mount`: unmount, новый `renderHook` → тот же список
  - `syncs from storage event of another tab`: `window.dispatchEvent(new StorageEvent('storage', { key: 'todo-app:v1', newValue: JSON.stringify([todo]) }))` → `todos` равно `[todo]`; событие с другим ключом игнорируется
- [ ] **Step 2:** Run — FAIL.
- [ ] **Step 3:** Реализовать: `useState(loadTodos)`, `useEffect(() => saveTodos(todos), [todos])`, подписка на `storage` в `useEffect` с отпиской. Действия через `useCallback` и функциональный `setState`.
