# To-Do List — дизайн-спецификация

Дата: 2026-11-03

## Цель

Тестовое задание: простой сайт «Список задач», который проверяющий смотрит
по коду и по живой ссылке на Vercel. Важны корректная работа, чистый код и
запоминающийся, аккуратный дизайн.

## Функциональность

1. **Добавление.** Поле ввода и кнопка «Добавить», Enter тоже добавляет.
   Пробелы по краям обрезаются. Пустая строка не добавляется. Длина текста
   ограничена 200 символами (`maxLength`). После добавления поле очищается,
   фокус остаётся в нём. Новая задача появляется в начале списка.
2. **Отметка выполнения.** Чекбокс у каждой задачи, повторный клик снимает
   отметку. Выполненная задача зачёркивается и приглушается, но остаётся на
   своём месте.
3. **Удаление.** Кнопка удаления у каждой задачи, без подтверждения.
4. **Сохранение.** Список хранится в `localStorage` под ключом
   `todo-app:v1` и восстанавливается после перезагрузки страницы.

Дополнительно: счётчик «осталось N из M» и полоса прогресса; пустое
состояние с подсказкой.

Синхронизация между вкладками: при изменении списка в другой вкладке
(событие `storage`) текущая вкладка подхватывает новый список, чтобы
вкладки не затирали данные друг друга.

Вне рамок: фильтры, редактирование текста, перетаскивание, бэкенд,
авторизация.

## Стек

React + Vite + TypeScript (актуальные версии из шаблона Vite). Обычный CSS (без UI-библиотек).
Шрифты подключаются пакетами `@fontsource` (кириллица, без внешних запросов).
Тесты: Vitest + React Testing Library + jsdom.

## Архитектура

```
src/
  types.ts              тип Todo { id, text, completed, createdAt }
  storage.ts            loadTodos() / saveTodos() — работа с localStorage
  useTodos.ts           хук: todos, add, toggle, remove; сохраняет при изменении
  components/
    TodoForm.tsx        поле ввода + кнопка
    TodoList.tsx        список или пустое состояние
    TodoItem.tsx        одна задача: чекбокс, текст, удаление
    Progress.tsx        счётчик и полоса прогресса
  App.tsx               шапка с датой + сборка компонентов
  index.css             токены цветов, темы, стили
```

- `storage.ts` — единственное место, знающее про `localStorage`.
  `loadTodos()` возвращает `[]`, если данных нет, JSON битый, это не массив
  или `localStorage` недоступен (приватный режим). Элементы неверной формы
  отбрасываются. `saveTodos()` глотает ошибки записи (переполнение квоты),
  чтобы интерфейс не падал.
- `useTodos` инициализирует состояние ленивым вызовом `loadTodos()` и
  сохраняет в `useEffect` при каждом изменении списка.
- `id` — `crypto.randomUUID()`, с запасным вариантом на случай отсутствия.

## Дизайн: «бумажный ежедневник»

Идея — страница печатного ежедневника, а не типовая карточка с тенью.

- **Палитра.** Светлая тема: тёплая бумага `#F3EDE2`, чернила `#1C1A17`,
  один акцент — киноварь `#D9482B`. Тёмная тема (по системной настройке):
  тёмная бумага `#17140F`, текст цвета слоновой кости `#EDE6D8`,
  акцент `#F0643F`. Все цвета заданы переменными на `:root`.
- **Фактура.** Лёгкий шум бумаги поверх фона (inline SVG), тонкие линейки
  между задачами, как в блокноте, и вертикальная красная линия полей слева.
- **Типографика.** Заголовок «Дела» крупным контрастным антиквенным
  шрифтом (Cormorant Garamond), под ним сегодняшняя дата по-русски
  («вторник, 3 ноября»). Текст задач — Manrope. Номера задач `01`, `02`…
  и счётчик — моноширинным JetBrains Mono.
- **Ввод.** Поле без рамки, только нижняя линия, как строка в блокноте;
  кнопка — круглая «печать» с плюсом цвета киновари.
- **Отметка.** Чекбокс — кружок, при отметке заливается акцентом с
  галочкой. Текст перечёркивается анимированной линией «от руки»
  (растягивается слева направо), строка приглушается.
- **Удаление.** Крестик справа; на компьютере появляется при наведении
  или фокусе, на сенсорных экранах виден всегда. Строка уходит с короткой
  анимацией схлопывания.
- **Прогресс.** Внизу страницы тонкая полоса и надпись
  `осталось 3 из 5`; когда всё выполнено — «Всё сделано».
- **Пустое состояние.** Курсивная строка «Чистая страница. Запишите
  первое дело.»
- **Mobile-first.** Базовые стили пишутся для телефона (от 320px), более
  широкие экраны добавляются через `@media (min-width: …)`. На телефоне
  поля 16px, без горизонтальной прокрутки, области нажатия не меньше 44px,
  шрифт поля ввода 16px (iOS не зумит страницу), учтены вырезы экрана
  (`env(safe-area-inset-*)`), форма ввода закреплена у нижнего края экрана
  в зоне большого пальца. На широких экранах — колонка до 640px по центру,
  форма под заголовком.
- **Доступность.** Подписи у поля и кнопок (`aria-label`), видимый фокус,
  список — `<ul>`, анимации отключаются при `prefers-reduced-motion`.

  SVG-фавикон и `apple-touch-icon`.

## Тестирование

Vitest + Testing Library:

- `storage`: пусто → `[]`; битый JSON → `[]`; не массив → `[]`;
  мусорные элементы отбрасываются; запись и чтение совпадают.
- `useTodos`: событие `storage` из другой вкладки обновляет список.
- `App`: добавление по кнопке и по Enter; пустой и пробельный ввод не
  добавляется; отметка и снятие отметки; удаление; после размонтирования и
  нового рендера задачи и их статус восстанавливаются из `localStorage`;
  счётчик обновляется.

Ручная проверка: `npm run build` без ошибок, просмотр в браузере на
ширине телефона и компьютера, в светлой и тёмной теме.
